# Ascension loadout auto-switch

In Settings → QoL → Ambrosia, turn on **Ascension loadout auto-switch** (off by default) and choose a saved slot under **Ascension loadout**. A successful manual ascension uses that tree for its rewards. Loading a different tree restarts the Ambrosia bars.

- On a patched game, the Ascend button and Shift+A reach the same manual reset. The patch wraps the synchronous reset after the game's confirmation, so canceling leaves the current tree alone. The mod validates and restores the player's live tree, including unsaved edits. It needs a marked slot or a remembered slot that matches the tree to restore through.
- Without the patch, the mod uses the game's Ascend button and its confirmation. It restores the previously marked saved slot after the game processes the reset. Load or save that slot before ascending so it contains any tree edits.
- A missing or unusable slot lets the game ascend with the current tree. AutoSing, the Hepteract Distributor's internal ascensions, and the game's Auto Ascend keep their own loadout behavior.
